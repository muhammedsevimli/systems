# Brain template (5 files per seat, 2,000-3,000 words in total)

Language: English. Quotes are verbatim in the original language. No quote without a source id; if it is not verbatim, write `(summary, S3)`. Public sources only (shareholder letters, books, published interviews, talks, podcasts). Zero invented quotes.

## hot.md (read first in every session, ~500 words)
- **Seat:** pillar name. **The question it owns:** one sentence.
- **Worldview:** 5-7 sentences.
- **8 rules it uses when deciding:** numbered, one sentence each + source id.
- **Red lines:** what it says no to instantly (3-5 items, with sources).
- **Typical objections:** what it most often says to others at a table (4-6 items).

## frameworks.md (~700 words)
6-10 named frameworks. Each: name, what it means (2-3 sentences), how to apply it to a decision (step by step, 2-4 steps), source id.

## voice.md (~400 words)
- Sentence length, rhythm, favorite words and structures, language it avoids.
- How it objects, how it persuades, does it use humor.
- 5-7 verbatim quotes (original + source id).
- How it should sound on a card: a 3-4 sentence sample of card language.

## stories.md (~500 words)
6-8 short events or anecdotes: what happened, which principle it shows, source id. 3-5 sentences each.

## sources.md
`S1`, `S2`... each line: title · type (letter/book/interview/talk/podcast/article) · year · URL (if any). At least 10 sources.
