## Settings
- threshold: 70

- listing_window: 1 day
- submit: no
- demo: yes
- time: 09:00

While `submit: no`, the agent fills in the form up to the last step, saves the "Review" screen and does not press the submit button. You submit it yourself. Once you trust the system, set `submit: yes`.

`demo: yes` is for trying the system with the fictional Elif Aydın CV that ships with the setup: the agent scans real listings, scores them, tailors the CV, fills in the form up to the "Review" step, then DISCARDS the draft. Nothing is submitted and no draft stays in the account. While `demo: yes`, `submit: yes` has no effect. When you enter your own CV, set `demo: no`.
