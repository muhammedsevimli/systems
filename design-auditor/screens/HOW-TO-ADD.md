# Put your screenshot here

This folder is the system's only input. You do not put code here, only images.

## How to capture

**Windows:** `Win + Shift + S` for a selection. For a full page, open devtools with `F12`, press `Ctrl + Shift + P`, type "Capture full size screenshot" and run it. That is the best option.
**Mac:** `Cmd + Shift + 4` for a selection. For a full page, `Cmd + Option + I` then `Cmd + Shift + P`, same command.
**Phone:** a normal screenshot is fine.

## File name
Name it after what it is, the system reads the file name:

```
home-desktop.png
home-mobile.png
pricing-desktop.png
```

## How many

| Situation | What to add |
|---|---|
| Fastest result | One full page desktop capture |
| Better audit | Desktop + mobile |
| Long page | Top half + bottom half, both desktop |

Add several images and the system treats them as parts of one page, not as separate reports.

## Watch out
- **Do not crop.** The outer margins are part of the measurement; crop them and alignment and spacing rhythm cannot be measured.
- Browser chrome and bookmarks can stay in the capture, the system does not count them.
- If the screenshot contains personal data (a real customer name, email or phone number), mask it. The system does not need it to audit.
